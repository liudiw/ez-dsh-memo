# dsh-memo — 便签墙

左栏常驻一个便签图标，点开就是一面便签墙：随手记下一闪而过的灵感，之后再回来整理。

## 有什么

- **左栏入口**（`sidebar.panellist` → `main`）：图标跟随侧栏选中态变色，提示文字走宿主语言（中文 / English）。
- **快速记录**：顶部一个输入框，`Enter` 保存、`Shift+Enter` 换行、`⌘/Ctrl + Enter` 保存（输入法组字时不会误提交）。
- **贴纸**：五种颜色（琥珀 / 玫瑰 / 天蓝 / 薄荷 / 紫罗兰），底色由「贴纸色 × 主题表面色」混出来，亮色 / 暗色主题都自适应，不写死背景色。
- **每张便签**：置顶、换色、双击（或铅笔按钮）编辑、删除（行内二次确认，不弹系统对话框）。
- **可改尺寸**：拖右下角把手即可自由拖宽拖高；**默认 260×150 同时也是缩小的下限**，宽度最多长到当前行右边缘（再宽会换行，所以拖到边缘就停），高度上限 900；把手双击 = 恢复默认；把手聚焦后方向键 ±16px、按住 Shift ±48px。
- **拖拽排序**：**按住便签本体**（移动超过 6px 才算拖，所以点选/双击编辑/选文字都不受影响）或按住右下角按钮行最左的三点手柄，拖到任意位置、松手才落盘；拖到置顶段之内会自动置顶，拖到之外自动取消置顶。拖拽时光标是抓手，被拖的便签**拎起来跟着指针走**（轻微放大 + 倾斜 + 投影），原位置留一个**透明虚线的占位框**标出松手落点，其余便签用 FLIP 动画（200ms）平滑让位；拖到列表上下边缘会自动滚动。
- **文字随尺寸自适应**：字号跟宽度走（宽度 160→900px 对应 11.5→15.5px，按 1:20 比例夹紧），窄便签字小、宽便签字大；高度固定后文字按可用空间重新排版，装不下就在便签内部滚动（细滚动条，不撑破卡片）；高度留空则随内容长。
- **搜索**：按内容即时过滤；置顶的永远在前，其余按创建时间倒序。
- **Markdown 渲染**：正文按 Markdown 子集渲染成富文本；双击进入编辑时看到的仍是 Markdown 原文（原文才是存储格式，渲染只是展示）。
- **同步到 fast-note-sync**：每张便签镜像成 vault 里的一个 Markdown（frontmatter 带颜色/置顶/尺寸），双向——Obsidian 里改正文、新建 md、重命名、删除都会同步回来。头部有颗状态胶囊，点一下立刻同步。
- **冲突不丢字**：两边都改过时按时间取新的一侧，败方正文另存一张标了「冲突副本」的便签。
- **持久化**：数据存在宿主侧 `~/.dsh/dsh-memo/notes.json`，浏览器只做展示——换浏览器、换设备看到的都是同一面墙。尺寸也一起存。
- **Agent 工具 `memo`**：`list` / `add` / `update` / `remove`，与界面共用同一个存储实现，所以你说「记一下……」，模型可以直接贴上墙。

## 数据与接口

- 数据文件：`~/.dsh/dsh-memo/notes.json`（原子写：写临时文件再 rename，写入串行化）
- 浏览器接口：`POST /dsh-memo/api`，请求体 `{ "method": "list|add|update|remove", "args": { … } }`，响应 `{ "ok": true, "result": { "notes": […] } }`
- 便签字段：`{ id, text, color, pinned, width, height, order, createdAt, updatedAt, remote?, syncConflict? }`
  - `width` / `height`：像素整数，`null` 表示「默认尺寸」（260×150）
  - 边界：宽 260–900，高 150–900（`index.js` 里的 `DEFAULT_NOTE_WIDTH`…`MAX_HEIGHT`）；越界会被夹紧，非法值按 `null` 处理
  - `order`：墙面上的手工顺序（越小越靠前）；老数据首次加载时按「置顶优先 + 创建时间倒序」自动补 0..n-1
  - `remote`：`{ path, lastTime, version, payloadHash, syncedAt }`，同步用的远端坐标与指纹（`payloadHash` 由宿主按存储内容计算，不接受外部传入）
  - `syncConflict`：真冲突时保留下来的「冲突副本」标记
- 顶层还有 `tombstones`（本地删掉的便签对应的远端路径，等同步去删）
- 布局：每张便签自带尺寸，所以墙是 flex 换行排版（不再用 CSS 多列），改尺寸时其余便签实时重排
- 上限：单条 4000 字、500 条（都写在 `index.js` 顶部的常量里）

## 图片

- **两种入口**：输入框底部的图片按钮（选文件）、或直接把图片**粘贴**到输入框 / 便签的编辑框里（`Ctrl/⌘+V`）。粘进去立刻上传并插入 `![](dsh-memo://…)`，保存后便签里就显示图片。
- **大图自动压缩**：长边超过 1600px 或超过 900KB 的图，会先在浏览器里缩到 1600px 再转 WebP（保留透明通道）；GIF 原样上传，不会被压成静态图。
- **存储（两份）**：
  1. **fast-note-sync 的 vault**：`attachments/<YYYY-MM-DD>/<sha256前24位>.<ext>`（日期取上传当天，目录名可在 `sync.json` 里用 `imageFolder` 改）。便签正文里写的是 vault 根路径 `![](/attachments/2026-11-04/xxx.png)`，**Obsidian 里能直接显示**。
  2. **宿主本地缓存** `~/.dsh/dsh-memo/images/<name>`：墙上的 `<img>` 走 `GET /dsh-memo/images/<name>`（一年不可变缓存），所以断网/没配同步也能看图。内容寻址，同一张图只存一份，远端路径记在 `images/index.json` 里，重复上传不会重复推。
  - 传远端失败（没网、没配同步）时自动降级成本地引用 `![](dsh-memo://<name>)`，墙上照常显示，控制台留一条 warn。上限单张 8MB。
  - **旧图自动迁移**：正文里还是 `dsh-memo://` 的老图片，启动 30 秒后会自动补传到 vault 并改写成 vault 路径（只改「内容没被同时改动」的便签，失败下轮再试，幂等）。
- **清理**：启动 20 秒后扫一次「没有任何便签引用、且放下超过一天」的图片并删除，避免越积越多。
- **Markdown 里**：写的是 `![](dsh-memo://<name>)`。注意这是**便签墙内部的引用**——同步到 vault 的 md 在 Obsidian 里显示不出来（图片文件不在 vault 里）。要的话我可以再加一步「把图片一起传到 fast-note-sync 的附件目录并改写成 Obsidian 能认的路径」。
- **归档**：分类栏的「归档」筛选；便签操作行的**归档盒**按钮一键归档/取消。归档的便签不在「全部/待办/分类」里出现，但数据保留（md 也留在 vault 里）
- **回收站**：删除不再是永久删除——进回收站保留 **7 天**（头部垃圾桶按钮进入，可「恢复/彻底删除/清空」；数据里是 `trash[]` + `deletedAt`）
- **撤销**：`Ctrl/Cmd+Z` 撤销最近一次改动（改文本/颜色/分类/提醒、拖拽排序、归档、删除、新建），最多 20 步；在输入框里仍走浏览器自带的文本撤销
- **清单勾选**：便签里写 `- [ ] 买牛奶` → 直接**点方框**就打勾（改的是正文里的 `[x]`）
- **搜索增强**：关键词命中处 `<mark>` 高亮；搜索框旁三个筛选开关——**有提醒 / 有图片 / 最近 7 天**，可与分类、关键词组合
- **每日回顾推送**：`remind.json` 里加 `daily: { "enabled": true, "time": "09:00" }`，到点推一条「今日待办 N 条（逾期 M）+ 待办清单 + 新增数」，同一天只推一次
- **会话页快速便签**：对话输入框右侧有个 📌 按钮（或任意界面按 **Alt+N**）→ 弹出「快速便签」小窗：写一句 **Enter 保存**（Shift+Enter 换行）、选颜色、**可顺手设提醒时间**（设了就自动成为待办）；下方列出**最近 5 条便签**（点一条直接跳到便签墙并打开它），还有「打开便签墙」入口。Esc 关闭
- **右侧便签抽屉**：对话输入框旁的列表按钮 → 从右侧滑出「便签」抽屉（可搜索、显示颜色点和提醒标记）；**点任意一条就在会话里浮出查看卡**（不切到便签墙、**不遮挡后面内容**、按住标题栏可拖拽、**拖右下角可改尺寸、文字自动重排**），卡里的 `[[双向链接]]` **点开就是另一张卡**（和便签墙里一致），**点空白只关抽屉、不关卡片**（卡片只能点右上角 × 或按 Esc 关闭，一次 Esc 关卡片、再按一次关抽屉）。底部可「快速便签」或「打开便签墙」（此时才是显式切过去）
- **快速便签归类**：面板里有个「🏷 分类（Alt+C）」按钮（不再是 `#` 语法，避免和 Markdown 标题冲突），点开或按 `Alt+C` 在**面板内就地展开**分类列表（**↑↓ 移动、空格勾选、回车/再按 Alt+C 关闭**；用的是普通文档流，不会被输入框或浮层遮住），选中后按钮显示分类名、保存时归到该分类
- **选中即存**：在任意页面选中一段文字（包括对话消息），旁边会浮出「存为便签」小气泡，点一下就把选中的内容带进快速便签
- **快速便签里看已有便签**：点列表里的一条 → 就地弹出**可拖拽悬浮卡**，快速便签窗口不关闭；卡里的 `[[链接]]` 还能继续点开
- **焦点回流**：关掉快速便签/抽屉后，焦点自动回到打开前的输入框；输入框里已有文字就把光标放到**末尾**。快速便签重新打开时，光标也在已输入内容的末尾（内容会保留）
- **快捷键**：`Alt+N` 快速便签、**`Alt+M` 便签抽屉**（**再按一次关闭**）、`Alt+C` 快速便签里的分类面板（↑↓ 移动、空格勾选、回车关闭）（设置 → 快捷键里能看到「快速便签」并改键）；注册成功时不再自带监听，不会双触发
- **弹层方向自适应**：便签靠左时，分类弹层 / 时间面板 / 色板会自动改成**向右展开**（`popSideFor` 比较锚点右边缘与面板左边），不再被 DSH 侧栏挡住
- **弹窗内直接编辑**：查看弹窗底部「编辑」→ 原地变成大文本域（同样支持 `[[` 补全），`⌘/Ctrl+Enter` 保存、`Esc` 取消；不用再回卡片里改
- **便签互链（wiki 链接）**：在便签/输入框里打 `[[` → 弹出可筛选的便签列表（↑↓ 选择、Enter/Tab 插入、Esc 取消）→ 变成 `[[便签标题]]`；标题 = 该便签第一行非空文本。查看态点链接会**叠一个可拖拽的浮窗**（原窗口不消失，按住标题栏拖动），浮窗里还能继续点链接逐层打开；没找到目标的链接显示为**红色删除线**（broken）。也支持 `[[标题|别名]]`
- **看全文**：便签内容被裁掉时，底部会出现**渐变 + ⌄**（点它或点操作行的**眼睛**按钮都行）→ 弹出限宽 720px 的阅读弹窗，完整渲染 Markdown（图片可点开大图），`Esc` 关闭、`←`/`→` 在当前筛选里连续翻，底部「编辑」直接进编辑态
- **自动排序**：标题右侧的九宫格按钮，一键把**当前筛选下可见的所有便签**恢复成默认尺寸（260×150）并重新装箱——墙立刻回到整齐排列。只动尺寸，不动分类/颜色/顺序。
- **查看大图**：查看状态下点便签里的图片 → 面板内弹出灯箱（先按窗口适应，可 `1:1` 看原尺寸）；**滚轮以光标为锚点缩放**（0.08×–10×）、**拖动平移**、`Esc` 或点空白关闭，底部显示缩放比例与原图分辨率。
- 安全性：只接受 png / jpeg / webp / gif 的 data URL；路由按白名单校验文件名，`../` 之类一律 404。

## 提醒（日程）

便签可以带一个提醒时间，等于给它加了个「时间维度」：

- **三种地方都能设**：**新建便签时**（输入框工具条右侧的闹钟按钮，面板**向上**展开、实色背景，选完在输入框里显示一个带 × 的时间 chip，提交后直接就是待办）、**编辑便签时**（编辑态工具栏里也有闹钟）、以及**查看态**便签操作行的闹钟
- **设置**：闹钟图标 → 面板里选日期时间 + 重复规则（不重复 / 每天 / 每周 / 每月），可清除、可标记完成；不设时间就是普通便签，设了就是待办
- **角标**：便签左下角显示 `今天 09:00` / `明天 09:00` / `11-08 09:00`，带重复后缀；到点变红并脉冲（`现在提醒`），提醒过但没完成的显示 `已逾期`（琥珀色），完成的显示 `已完成`
- **待办视图**：分类栏最前面一个「待办」筛选，按提醒时间正序（到点/逾期的自然排最前）
- **触发**：宿主每 15 秒扫一次，到点就原子地「标记 + 推进」——一次性提醒保留时间（继续显示逾期直到你勾完成），重复提醒自动推到下一次
- **通知（不自动消失）**：提示条挂在 `shell.overlay`（框架级浮层），**切到任何面板都能看到，而且一直留着**——直到你点「完成」（不再提醒）、「延后 5 分钟」（5 分钟后再响）或「关闭」；同时来了多条时有「全部关闭」。同时发系统通知（首次保存提醒时会申请权限）
- **墙上也能看出来**：分类栏的「待办」在**有到点未处理**的便签时变红并显示数量；便签角标：到点=红色脉冲 `现在提醒`、提醒过但没完成=琥珀色 `已逾期`、未来=灰色时间
- **不静默失败**：保存后立刻回执一条「提醒已设为 今天 19:09」；没选时间会留在面板里提示，不会悄悄关掉
- **默认与快捷**：打开面板默认填「10 分钟后」，另有 `1 分钟后`（方便自测）、`10 分钟后`、`1 小时后`、`明天 9:00` 四个快捷键
- **错过也补**：宿主启动时先扫一次，关机期间到点的提醒会立刻补一次；重复提醒会跳过中间那些次，直接推到下一个未来时刻

### 推送通道（可选，手机不打开网页也能收到）

写 `~/.dsh/dsh-memo/remind.json`（不写就只在网页里提醒）：

```json
{
  "enabled": true,
  "url": "https://qyapi.weixin.qq.com/cgi-bin/webhook/send?key=xxx",
  "method": "POST",
  "contentType": "application/json",
  "body": "{\"msgtype\":\"text\",\"text\":{\"content\":\"⏰ {{text}}\"}}"
}
```

模板里可用 `{{text}}`（便签正文）、`{{time}}`（这次提醒的时刻）、`{{id}}`（便签 id）；`contentType` 含 `json` 时自动做 JSON 转义。

- **企业微信机器人**：`url` 用群机器人 webhook，`body` 如上
- **ntfy**：`url` 用 `https://ntfy.sh/你的主题`，`contentType: "text/plain"`，`body: "⏰ {{text}}"`
- **PushDeer**：`url` 用 `https://api2.pushdeer.com/message/push?pushkey=xxx&text=...`，`contentType: "text/plain"`

### 数据与 markdown

```yaml
dsh-memo-remind: 2026-11-05T09:30:00+08:00
dsh-memo-repeat: weekly:3     # daily / weekly:<0-6> / monthly
dsh-memo-done: true           # 完成才写
```

提醒字段也算进 `payloadHash`，所以改提醒时间会正常同步到 md，不会和远端正文互相覆盖。

## 手机端

- **做成 App（PWA / WebAPK）**：插件会往页面注入 `manifest`（名称「便签墙」、`start_url: /#memo`、`display: standalone`、192/512 图标 + maskable、主题色）并提供一个**惰性 service worker**（不接管任何请求，只为满足部分 Chrome 的安装判定，`Service-Worker-Allowed: /`）。手机 Chrome 打开站点 → 菜单「**添加到主屏幕**」→ 桌面出现独立图标，全屏打开、直接落在便签墙；iOS Safari「添加到主屏幕」同样可用（走 `apple-touch-icon`）。需要 HTTPS——tailnet 域名本来就是。
- **深链**：URL 带 `#memo`（或 `?panel=memo`）会直接打开便签墙——把书签/主屏快捷方式设成 `https://<你的域名>/#memo` 就能一步进去。
- **窄屏适配**（≤640px）：分类栏改成横向滚动、工具按钮加大到 30px、便签默认**占满一整行**（手动调过尺寸的保持原尺寸）、触屏设备上操作按钮和缩放手柄常显（没有 hover 也不会点不到）。
- 访问方式见 [[环境·Nest与大春]] 里的 tailnet 说明；首次用 `?token=…` 换一次 30 天有效期的签名 cookie，之后书签不用再带 token。

## 分类（多对多）

- 顶部一条**分类栏**：`全部` / 每个分类（带便签计数）/ `未分类`（有这类便签时才出现）/ `+ 新分类`。
- 点分类胶囊 = 只看这个分类；再点 `全部` 回到全览。
- 悬停分类胶囊会出现两个小按钮：**重命名**（原地变输入框，回车确认、Esc 取消）和**删除**（行内二次确认）。删除分类会把便签上对它的引用一并摘掉，不会删便签。
- 一张便签可以**同时属于多个分类**：便签右下角操作行里的**标签按钮**打开多选清单，点一下挂上/摘下；便签左下角会显示所属分类的小胶囊，点它直接筛到这个分类。
- Agent 也能用：给 `memo` 工具传 `categories: ["工作","生活"]` 即可（不存在的分类会自动创建），`list` 结果里每条便签都带 `categories` 与全部现有分类名。
- **分类是本地概念**（存在 `notes.json` 里），不写进 vault 的 Markdown——这样同步链路完全不用为分类操心，vault 的 md 也不会因为改分类而反复重写。如果你希望分类也出现在 md 的 frontmatter 里，说一声，我加个单向标注。

## Markdown 支持

渲染器是随插件内联的 ~150 行受控实现（客户端半不能引第三方库），**只生成 React 元素、不拼 HTML 字符串**，所以不需要额外净化：文本永远走 textContent 路径，写 `<script>` 只会显示成字面量。

| 写法 | 效果 |
|---|---|
| `# / ## / ###` | 标题（渲染成 h3–h6，按 1.34/1.22/1.1em 缩放） |
| `**粗**`、`*斜*`、`~~删~~`、`` `代码` `` | 行内样式；行内代码优先，`` `**x**` `` 不会被当成粗体 |
| ` ```js ` 围栏 | 代码块（等宽、可横向滚动，保留原文缩进） |
| `- / * / +`、`1.` | 无序 / 有序列表；缩进续行并进同一项 |
| `- [ ] / - [x]` | 任务列表（勾选框只做展示，不可点） |
| `> 引用` | 引用块（左侧细线 + 次要文字色） |
| `---` | 分隔线 |
| `[文字](https://…)`、裸 `https://…` | 链接；**只允许 http/https/mailto**，其余（`javascript:`、`data:`…）退化成纯文本 |
| `[[某篇笔记]]` | 双链样式的小胶囊（只做展示，点击不跳转） |
| `\|a\|b\|` + `\|---\|:-:\|` | 表格（GFM）：支持 `:-:` 居中、`--:` 右对齐；列多时表格自己横向滚动，不撑破便签 |
| 空行 / 单个换行 | 分段 / 段内软换行（与 Obsidian 默认一致） |

图片语法先按原文显示（不发起外部请求）。这些元素全部用主题 token 着色，亮/暗主题都自适应。

## 同步到 fast-note-sync（可选）

配置放在 `~/.dsh/dsh-memo/sync.json`（`chmod 600`，**含 API 令牌，别提交到任何仓库**）：

```json
{
  "enabled": true,
  "api": "https://obsidian-fns.iepose.cn",
  "apiToken": "<从 FNS 网页端生成的 API 令牌>",
  "vault": "Memo Vault",
  "folder": "便签墙",
  "intervalMs": 60000
}
```

- `api` 可以带不带 `/api` 后缀；`folder` 是 vault 里的目录（默认 `便签墙`）；`intervalMs` 是后台轮询间隔（最短 15s）。
- 没有这个文件 / 字段不全 / JSON 坏掉 → 同步自动关闭，便签墙照常本地可用，界面上不显示同步胶囊。
- 令牌是「服务端密钥 + 机器 ID」签名的，**只能由同一个 FNS 实例生成**；换了实例要重新生成。

### 落地的 Markdown 长什么样

`便签墙/2026-11-03-2237-摘语片段-f294.md`：

```markdown
---
dsh-memo-id: f2940a7f-9158-4608-be2c-cb276b152341
created: 2026-11-03T14:37:26.652Z
dsh-memo-color: rose
dsh-memo-pinned: true
dsh-memo-width: 372
dsh-memo-height: 208
---

便签正文，原样保留换行。
```

文件名只在首次推送时生成；之后改正文沿用同一个文件（不会在 vault 里越推越多）。

### 双向语义

| 场景 | 行为 |
|---|---|
| 本地新增/改正文/换色/置顶/改尺寸 | 推送（新增用 `POST /api/note`，有映射则原地覆盖） |
| 在 Obsidian 里改正文/颜色/置顶/尺寸 | 拉回本地 |
| 在 Obsidian 里**新建** md（放在 `folder` 目录里） | 导入成便签，frontmatter 里的颜色/置顶/尺寸生效 |
| 在 Obsidian 里**重命名** md | 靠 frontmatter 的 `dsh-memo-id` 认回原便签（rebind），不会变成两条 |
| 在 Obsidian 里**删除** md | 本地便签跟随删除（远端是进回收站，能救回） |
| 本地删除便签 | 远端对应的 md 进回收站（删不掉的记成「墓碑」，下次重试） |
| 两边都改过（真冲突） | **一律本地优先**（不比两台的墙钟——机器差几秒就会随机翻转判定）；远端那份正文另存一张标「冲突副本」的便签，不丢字。单轮最多 5 份、同一文案只留一份 |

同步失败不会挡住本地写入：先落 `notes.json`，失败只在日志里告警、界面上胶囊变红，下次再试。
Agent 也可以用 `memo` 工具的 `sync` 动作手动触发一次。

## 安装 / 卸载

用 `plugin_manager` 安装本目录（bundle 名 `@local/dsh-memo`，行 id `dsh-memo`），安装后左栏即出现图标；停用该 bundle 即从侧栏消失，数据文件保留。

## 让 AI 读写便签

插件注册了一个宿主工具 `memo`，模型操作的就是你看到的这面墙：

- `list` 读全部（正文、颜色、置顶、分类、提醒）
- `add` 新建（可带 `color` / `pinned` / `categories` / `remindAt` / `repeat`）
- `update` 按 id 改正文/颜色/置顶/分类/提醒/完成
- `remove` 删除（进 7 天回收站）
- `sync` 立刻同步一次 fast-note-sync

示例：*「把关于项目 A 的便签归到工作分类」*、*「列出我逾期的待办」*、*「给这条加明天 9 点的提醒」*。
